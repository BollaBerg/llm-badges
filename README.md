# LLM-Badges

[![Fully generated](https://bollaberg.github.io/llm-badges/assets/fully-generated.svg)](https://bollaberg.github.io/llm-badges/badge-detail.html?id=fully-generated)

A set of pre-determined badges for project READMEs to indicate the level of LLM involvement in code generation. Fully AI-generated using Gemini CLI, to learn more about how that works.

## Usage

To use a badge in your project, simply go to [this project's pages](https://bollaberg.github.io/llm-badges/index.html), click your badge, then click the "Copy as markdown" button.

## Badge Definitions

| Name | Description | Example |
| :--- | :---------- | :------ |
| **Fully hand-crafted** | This code is fully hand-made. | [![Fully hand-crafted](https://bollaberg.github.io/llm-badges/assets/fully-hand-crafted.svg)](https://bollaberg.github.io/llm-badges/badge-detail.html?id=fully-hand-crafted) |
| **Content is hand-crafted** | The code for this project is partially generated by an LLM, but the content (e.g., blog posts) are hand-crafted by a human. | [![Content is hand-crafted](https://bollaberg.github.io/llm-badges/assets/content-hand-crafted.svg)](https://bollaberg.github.io/llm-badges/badge-detail.html?id=content-hand-crafted) |
| **Partially generated** | This code is partially generated by an LLM. Some of it is hand-made. | [![Partially generated](https://bollaberg.github.io/llm-badges/assets/partially-generated.svg)](https://bollaberg.github.io/llm-badges/badge-detail.html?id=partially-generated) |
| **Fully generated** | This project is fully generated by an LLM. | [![Fully generated](https://bollaberg.github.io/llm-badges/assets/fully-generated.svg)](https://bollaberg.github.io/llm-badges/badge-detail.html?id=fully-generated) |

## Development

This project is a website (hosted on GitHub Pages) that showcases these badges and provides convenient ways to copy them as markdown or HTML for use in other projects.

### Running Locally

This is pure HTML/CSS/JS. To view the website locally, simply open [index.html](index.html) and take it from there.

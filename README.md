# Project: Badges

A set of pre-determined badges for project READMEs to indicate the level of LLM involvement in code generation.

## Badge Definitions

- **Fully hand-crafted:** This code is fully hand-made. (Color: GREEN)
- **Partially generated:** This code is partially generated by an LLM. Some of it is hand-made. (Color: ORANGE)
- **Content is hand-crafted:** The code for this project is partially generated by an LLM, but the content (e.g., blog posts) are hand-crafted by a human. (Color: YELLOW)
- **Fully generated:** This project is fully generated by an LLM. (Color: RED)

## Development

This project is a website (hosted on GitHub Pages) that showcases these badges and provides convenient ways to copy them as markdown for use in other projects.

# Project Mandates

- **Incremental Development:** Perform changes in small, bite-sized increments.
- **Atomic Commits:** Each logical change or sub-task must be committed to Git immediately after validation.
- **Commit Prefix:** Prefix every commit message with "GEMINI: " to differentiate agent changes.
- **README Maintenance:** Always ensure the README is up to date with any changes performed. It should contain a brief summary of the project, as well as any commands necessary to run (and deploy) the project locally.
